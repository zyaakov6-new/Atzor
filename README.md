# Atzor

Monorepo for the Atzor project.

- **`atzor-app/`** — the mobile app (Android + iOS).
- **`atzor-landing/`** — the landing page and its API (deployed on Vercel).

Each folder keeps its own README, `.gitignore`, and build setup; see those for
per-project instructions.

Build output, dependencies, signing material (keystores, `keystore.properties`)
and environment files are deliberately not versioned here.
